# 陈／望资金测试版

这是外援分支的独立启动模式，方便反复招募、升级商店和试用干员。所有玩家（包括 AI）的对局资金从战前简报到结束都固定为 **99**，购买、刷新、升级不会降低余额，出售与收入也不会提高余额。

## 一键启动

Windows 双击项目根目录的 **`启动干员测试版.bat`**。脚本沿用原项目的依赖与素材准备流程，自动启动服务器并打开浏览器，默认地址为 **http://localhost:3001**。终端会显示「干员测试版：对局资金固定 99」。

也可以在项目根目录运行：

```text
npm run playtest
```

首次启动会准备依赖与本地素材；已有素材直接复用。关闭启动窗口或按 Ctrl+C 停止测试服务器。可传入原启动器的参数，例如 `启动干员测试版.bat --port 3002`、`npm run playtest -- --no-setup`。

正常启动入口仍使用正常经济规则。测试入口默认使用另一个端口；如果指定端口已运行正常版，测试入口会明确拒绝，避免打开错误版本。

## 测试干员

1. 在「干员调配」的五／六阶外援位置选择陈、望；同一玩家不能重复选择同一干员。选择仍由玩家自行设置，不自动替换已有预设。
2. 选择要验证的技能和模组，创建独立模拟或同盟模拟。
3. 休整期反复点击升级，将调度中心升到六级，再刷新、招募、精锐化和部署。资金保持 99，仍需有手牌空间和对应卡池份数。
4. 朋友或手机玩家访问这台测试服务器的局域网地址及测试端口；同一测试服务器上的所有房间都使用固定资金。

测试版只改变资金余额。卡池、盟约、干员数值、技能、模组、商店价格、免费刷新次数、召唤物、部署费用与冷却均沿用外援分支。原支付与收入事件仍会触发，所以消耗资金的战报统计及依赖支付事件的盟约继续按原规则工作；它们不会减少测试余额。

**陈、望各阶形态均仅有【炎】盟约。陈的三技能剑气撞墙后顺时针转向：上→右→下→左→上。** 已用五／六阶、初始／精锐、四个部署方向及连续两次碰墙验证。
